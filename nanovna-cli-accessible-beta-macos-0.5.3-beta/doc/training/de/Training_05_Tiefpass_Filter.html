Training Szenario 5: Tiefpass-Filter (mit S21-Transmission)

Trainingsdatei: Training/05_tiefpass_filter.csv Frequenzbereich: 144.000 - 146.000 MHz (2m Amateurfunkband) Schwierigkeitsgrad: ⭐⭐ Mittel Lernziel: Verstehen von Filtern durch S21-Transmissions-Messung und Kombination S11+S21

📋 Szenario-Beschreibung

Fiktive Komponente

Sie messen einen Tiefpass-Filter für 2m-Band. Der Filter ist so ausgelegt, dass er Frequenzen bis ~145 MHz mit minimaler Dämpfung durchlässt, aber höhere Frequenzen zunehmend dämpft. Dieser Typ Filter wird in Sendern zur Oberwellen-Unterdrückung eingesetzt.

Technische Eigenschaften

  • Impedanz (S11): 50.1Ω + j0.1Ω (sehr gut angepasst über gesamtes Band)
  • SWR: 1.00 bis 1.09 (exzellent!)
  • Return Loss (S11): 26.48 bis 54.10 dB (sehr gut)
  • Transmission (S21):
  • 144.0 MHz: -0.015 dB (99.5% Durchlass)
  • 145.0 MHz: -0.10 dB (99.0% Durchlass)
  • 146.0 MHz: -0.15 dB (98.5% Durchlass)
  • Besonderheit: Erste Training-Datei mit S21-Daten!

Physikalische Bedeutung

Ein Tiefpass-Filter besteht typisch aus:

  • Serie-Induktivitäten: Sperren hohe Frequenzen
  • Parallel-Kapazitäten: Leiten hohe Frequenzen nach Masse ab
  • Design-Ziel: Maximaler Durchlass im Nutzband, maximale Dämpfung darüber

Typische Anwendungen:

  • Oberwellen-Filter in HF-Sendern (gesetzlich oft erforderlich!)
  • EMV-Filter (Schutz vor HF-Einstrahlung)
  • PA-Ausgangsfilter (Transceiver, Endstufen)
  • Harmonics-Suppression für Amateurfunk-Sender

Wichtigkeit:

  • Oberwellen (2×f, 3×f, ...) können Fernseh-/Rundfunkempfang stören
  • Gesetzliche Grenzwerte für unerwünschte Aussendungen
  • Gute Filter: < -40 dB Dämpfung bei 2. Oberwelle

🎵 Erwartete Audio-Ereignisse

Reflexions-Parameter (S11) - Eingangs-Anpassung

1. SWR-Kurve (Taste 1 - Sinuswelle)

Was Sie hören sollten:

  • Extrem leiser, sehr tiefer Dauerton (ähnlich Szenario 1!)
  • SWR steigt ganz leicht von 1.00 bis 1.09
  • Minimal hörbarer Aufwärtstrend
  • Nahezu konstant über gesamtes Band

Bedeutung:

  • Filter ist perfekt angepasst an 50Ω-System
  • Eingangsimpedanz bleibt 50Ω (fast keine Reflexion)
  • Dies ist Qualitätsmerkmal eines guten Filters!
  • Unterschied zu Antennen: Filter MUSS breitbandig angepasst sein

Position im Stereofeld:

  • Sound bleibt zentriert (gleiche Anpassung über Band)
  • Keine bedeutende Links-Rechts-Bewegung

2. Return Loss Kurve (Taste 2 - Reine Sinuswelle)

Was Sie hören sollten:

  • Sehr hoher Ton (26-54 dB)
  • Leichte Variation, aber durchgehend hoch
  • Ton "flattert" leicht über Frequenz

Bedeutung:

  • Hoher Return Loss = Wenig Reflexion = Gute Anpassung
  • Filter reflektiert kaum Energie zurück zum Sender
  • Sender "sieht" 50Ω-Last über gesamtes Band

3. Impedanz |Z| (Taste 3 - Dreieckswelle)

Was Sie hören sollten:

  • Konstanter mittlerer Ton um 50Ω
  • Steigt minimal von 50.1Ω auf 52.3Ω
  • Sehr stabiler Dreieckswellen-Klang
  • Fast keine Tonhöhenänderung wahrnehmbar

Bedeutung:

  • Impedanz bleibt sehr nah bei 50Ω
  • Filter ist resistiv über gesamtes Band
  • Kein nennenswerter Blindanteil

4. Reaktanz X (Taste 4 - Sägezahn)

Was Sie hören sollten:

  • Extrem leiser Ton um Nulllinie
  • Steigt minimal von +0.2Ω auf +2.0Ω (kaum hörbar)
  • Sehr leichter Aufwärtstrend (leicht induktiv)
  • Bleibt im neutralen Bereich

Bedeutung:

  • Fast keine Reaktanz = Nahezu rein resistiv
  • Minimale Induktivität durch Filter-Spulen
  • Hervorragendes Filter-Design!

5. Phase (Taste 5 - Sinuswelle)

Was Sie hören sollten:

  • Sehr leiser Ton nahe Nullpunkt
  • Minimale Phasenänderung über Band
  • Phase bleibt nahezu konstant

Bedeutung:

  • Geringe Phase = Widerstand dominiert
  • Filter verursacht minimale Phasenverschiebung im Durchlassbereich

Transmissions-Parameter (S21) - Durchlass-Charakteristik ⭐

6. S21 Magnitude (Transmission Loss) - NEU!

Aktivieren:

  • Im akustischen Modus: Taste 6 oder Taste T

Was Sie hören sollten:

  • Sehr leiser, langsam absinkender Ton
  • Beginnt bei fast unhörbarem Niveau (-0.015 dB bei 144 MHz)
  • Sinkt leicht ab über Frequenz
  • Endet bei leicht tieferem, aber immer noch hohem Ton (-0.15 dB bei 146 MHz)

Bedeutung:

  • S21 = Transmissionsfaktor (wie viel Signal kommt durch?)
  • Hoher Ton = Geringe Dämpfung = Viel Signal kommt durch
  • Absinkender Ton = Tiefpass-Charakteristik!
  • Niedrige Frequenzen: Besser durchgelassen
  • Höhere Frequenzen: Stärker gedämpft
  • Im 2m-Band: Nur 0.15 dB Dämpfung = Exzellent!

Vergleich mit anderen Werten:

S21 (dB)  | Transmission | Was es bedeutet

----------|--------------|------------------ 0 dB      | 100%         | Perfekt (unmöglich in Praxis) -0.1 dB   | 99%          | Hervorragend (dieser Filter!) -1 dB     | 89%          | Sehr gut -3 dB     | 50%          | Halbierung der Leistung -10 dB    | 10%          | Starke Dämpfung -40 dB    | 0.01%        | Fast vollständige Sperrung

Stereo-Position:

  • Sound bewegt sich leicht nach unten (Frequenz steigt, Dämpfung nimmt zu)
  • Zeigt Tiefpass-Charakteristik räumlich

7. S21 Phase (Transmissions-Phase) - NEU!

Aktivieren:

  • Im akustischen Modus: Taste 7 oder Taste P

Was Sie hören sollten:

  • Absinkender Ton (Phase wird negativer)
  • Beginnt bei ca. -1° bis -2° (fast null)
  • Sinkt auf ca. -15° bis -20° bei 146 MHz
  • Kontinuierlicher Abwärtstrend

Bedeutung:

  • S21 Phase = Phasenverzögerung durch Filter
  • Negative Phase = Signal verzögert (normale Eigenschaft von Filtern)
  • Zunehmende Verzögerung = Group Delay des Filters
  • Lineare Phase über Frequenz = Gutes Filter-Design

Praktische Bedeutung:

  • Geringe Phasenverzögerung = Minimale Signalverzerrung
  • Wichtig für Digitale Übertragung (RTTY, FT8, etc.)
  • SSB-Telefonie: Meist unkritisch

Übung 1: S11 vs. S21 verstehen

Ziel: Unterschied zwischen Reflexion und Transmission begreifen

  1. Alle Kurven ausschalten (Tasten 1-7)

  1. SWR ausschalten (Taste 1)
  2. Nur S21 Magnitude einschalten (Taste 6)

  1. Beide zusammen einschalten (Taste 1 + Taste 6)

Interpretation:

  • S11 (SWR): Sagt, ob Quelle gut angepasst ist
  • S21 (Transmission): Sagt, ob Signal durchkommt

🎓 Lernziele und Interpretation

Was Sie aus diesem Szenario lernen

1. S-Parameter-Konzept verstehen

  • S11: Reflexion am Eingang (wie bei Antennen)
  • S21: Transmission von Port 1 zu Port 2 (nur bei Zweitoren!)
  • S12: Transmission rückwärts (hier nicht gemessen)
  • S22: Reflexion am Ausgang (hier nicht gemessen)

Merksatz:

  • Eintore (Antennen): Nur S11
  • Zweitore (Filter, Verstärker, Kabel): S11 + S21 (+ S12 + S22)

2. Filter-Qualitätskriterien

Guter Tiefpass:

  1. Niedrige Einfügedämpfung im Durchlassbereich (< 1 dB)
  2. Gute Anpassung (SWR < 1.5) über Durchlassbereich
  3. Steile Flanke (Dämpfung steigt schnell über Grenzfrequenz)
  4. Hohe Sperrung im Sperrbereich (> 40 dB bei 2. Oberwelle)

3. Akustische Signaturen für Filter

  • S11 (SWR): Sollte tief und konstant sein (gute Anpassung)
  • S21 Magnitude:
  • Tiefpass: Absinkend mit Frequenz
  • Hochpass: Ansteigend mit Frequenz
  • Bandpass: Peak in der Mitte, Flanken links/rechts
  • Bandsperre: Einbruch in der Mitte
  • S21 Phase: Meist linear absinkend (Group Delay)

4. Unterschied: Anpassung vs. Durchlass

  • Gute Anpassung (S11) bedeutet NICHT automatisch guten Durchlass (S21)!
  • Beispiel: Perfekt angepasster Dämpfer (50Ω)
  • S11: Perfekt (SWR=1.0)
  • S21: Schlecht (-10 dB oder mehr)
  • Beide Parameter sind wichtig!

5. Praxisbezug

  • Sender ohne Tiefpass: Oberwellen stören Nachbarn (gesetzlich problematisch!)
  • Sender mit Tiefpass: Sauber, legal, nachbarfreundlich
  • Messung: S11 + S21 komplett charakterisieren Filter
  • Design: Kompromiss zwischen Dämpfung, Flanke, Größe, Kosten

⚠️ Wichtige Hinweise

Realitätscheck: Filter in der Praxis

Typische Einfügedämpfung (Insertion Loss):

  • Professionelle Filter: 0.1 - 0.5 dB
  • Amateur-Selbstbau: 0.5 - 1.5 dB
  • Billige Filter: 1 - 3 dB
  • Akzeptabel für QRP: < 1 dB
  • Akzeptabel für QRO: < 0.5 dB

Beispiel-Rechnung:

Sender: 100W

Filter: 0.15 dB Dämpfung Verlust: 100W × (1 - 10^(-0.15/10)) = 100W × 0.034 = 3.4W  Ergebnis: 96.6W kommen an Antenne an → Akzeptabel!

Oberwellen-Dämpfung:

  • Gesetzliche Anforderung (EU): < -40 dBc (dB bezogen auf Carrier)
  • Gute Praxis: < -50 dBc
  • Exzellent: < -60 dBc

Messtechnik-Aspekt

S21-Messung erfordert:

  1. Zweiten Port am VNA (NanoVNA hat 2 Ports!)
  2. Through-Kalibrierung (Port 1 direkt mit Port 2 verbinden)
  3. Isolation-Kalibrierung (Ports offen lassen)
  4. Filter zwischen Ports anschließen

Kalibrierungs-Reihenfolge:

  1. OPEN (beide Ports offen)
  2. SHORT (beide Ports kurzgeschlossen)
  3. LOAD (beide Ports mit 50Ω terminiert)
  4. THROUGH (Port 1 direkt mit Port 2)
  5. ISOLATION (Ports offen, Messung des Übersprechens)

Filter-Design-Grundlagen

Tiefpass-Topologien:

  1. LC-Leiterfilter: Günstig, einfach, verlustarm
  2. Pi-Filter: Kompakt, gute Impedanzanpassung
  3. T-Filter: Ähnlich Pi-Filter
  4. Tschebyscheff: Steile Flanke, Welligkeit im Durchlass
  5. Butterworth: Flacher Durchlass, weniger steile Flanke
  6. Bessel: Lineare Phase (wichtig für Digitalmoden)

Grenzfrequenz vs. Nutzfrequenz:

  • Grenzfrequenz (-3 dB): Wo Leistung halbiert ist
  • Nutzbereich: Sollte deutlich VOR Grenzfrequenz liegen
  • Faustregel: Grenzfrequenz ≥ 1.5 × max. Nutzfrequenz

🔬 Vertiefung: S-Parameter-Theorie

Was sind S-Parameter?

Definition:

S-Parameter = Streuparameter (Scattering Parameters)

S21 = b2 / a1  (bei a2 = 0) b2 = Welle, die aus Port 2 herauskommt a1 = Welle, die in Port 1 hineingeht  → S21 beschreibt Transmission von Port 1 zu Port 2

In Dezibel:

S21 (dB) = 20 × log10(|S21|)

Beispiele: |S21| = 1.0   → S21 = 0 dB    (perfekt, keine Dämpfung) |S21| = 0.99  → S21 ≈ -0.1 dB (dieser Filter!) |S21| = 0.5   → S21 = -6 dB   (halbe Spannung) |S21| = 0.1   → S21 = -20 dB  (stark gedämpft)

In Leistung:

P_out / P_in = |S21|²

Beispiel: S21 = -0.15 dB |S21| = 10^(-0.15/20) = 0.983 P_out / P_in = 0.983² = 0.966 = 96.6%  → 3.4% Leistung wird im Filter absorbiert

Warum ist S21 wichtig?

  1. Filter: S21 zeigt Frequenzgang (Durchlass/Sperre)
  2. Verstärker: S21 zeigt Gewinn (z.B. +20 dB)
  3. Kabel: S21 zeigt Dämpfung (frequenzabhängig)
  4. Schalter: S21 zeigt Isolation (ON vs. OFF)
  5. Mixer: S21 zeigt Conversion Loss

Praktischer Tipp:

  • Wenn Sie "Anpassung" wissen wollen → Messen Sie S11!
